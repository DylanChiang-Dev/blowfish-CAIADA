# 官網倉庫架構重整計劃 v0.0.1

日期：2026-05-22

## 背景與問題

倉庫 `blowfish-CAIADA` 目前是把 Blowfish 主題的**開發倉庫**直接當作協會官網使用。核心問題：

| 問題 | 嚴重度 |
|---|---|
| 啟動命令需特殊參數，`npm run example` 無法正常啟動 | 🔴 高 |
| 無法追蹤上游 Blowfish 主題更新 | 🔴 高 |
| `baseURL = "https://localhost:1313"` 導致本地開發連不上 | 🟡 中 |
| `params.toml` 殘留上游設定（buymeacoffee、editURL 指向上游） | 🟡 中 |
| 大量主題原始碼（tailwind.config.js 等開發工具）污染倉庫 | 🟡 中 |
| CF Pages 的建置根目錄需設為 `exampleSite`，部署配置額外複雜 | 🟡 中 |

## 決策

**在原倉庫原地重整（不新建倉庫）**，使用 **Git Submodule** 引入官方 Blowfish 主題。倉庫根目錄直接成為 Hugo 網站根。

## 目標結構

```
blowfish-CAIADA/                   ← 倉庫根，直接是網站根
├── .gitmodules                    ← 聲明 Blowfish 為 submodule
├── themes/
│   └── blowfish/                  ← 官方主題（git submodule，main branch）
├── content/                       ← 從 exampleSite/content/ 遷移
├── assets/
│   └── img/                       ← 僅協會自己的圖片
├── config/
│   └── _default/
│       ├── hugo.toml              ← theme = "blowfish"，baseURL 正確
│       ├── params.toml            ← 清除所有上游殘留設定
│       ├── languages.*.toml
│       └── menus.*.toml
├── plans/                         ← 本計劃與後續技術計劃
├── AGENTS.md                      ← 更新啟動命令與部署說明
├── RULES.md
├── MEMORY.md
└── README.md
```

## 本地開發命令（重整後）

```bash
# 開發模式（就這一行，不需要任何特殊參數）
hugo server

# 生產建置
hugo --minify --gc
```

## Cloudflare Pages 配置變更

| 設定項 | 重整前 | 重整後 |
|---|---|---|
| 建置命令 | `hugo --minify --gc` | `hugo --minify --gc` |
| 輸出目錄 | `public` | `public` |
| **根目錄** | `exampleSite` | **`/`（倉庫根）** ← 需在 CF Pages 後台更改 |
| `HUGO_VERSION` | `0.150.1` | `0.161.1` |

## 實施步驟

### 階段一：備份確認
1. `git status --short` 確認沒有未提交的修改
2. 記錄需保留的檔案清單（content、assets/img/news、config、data）

### 階段二：清理主題原始碼
3. 刪除所有屬於主題本體、協會不需要修改的檔案：
   - JS 工具：`tailwind.config.js`、`lighthouserc.js`、`genArticle.js`、`genLang.js`、`genLangLinks.js`、`findMissingTranslations.js`、`processUsers.js`
   - 上游圖片：`blowfish_logo.png`、`logo.png`
   - 上游主題文件：`theme.toml`、`release-versions/`、`images/`
   - 配置衝突：`config.toml`（根目錄舊配置）
   - 主題本體目錄：`assets/`、`layouts/`、`i18n/`、`static/`、`archetypes/`、`data/`
   - Go 模組：`go.mod`（主題的 module ID）
   - Node 工具鏈：`package.json`、`package-lock.json`、`node_modules/`
4. 遷移 `exampleSite/content/` → 根目錄 `content/`
5. 遷移 `exampleSite/assets/img/` → 根目錄 `assets/img/`
6. 遷移 `exampleSite/config/_default/` → 根目錄 `config/_default/`
7. 刪除 `exampleSite/` 整個目錄

### 階段三：初始化新結構
8. 加入 Blowfish 官方主題為 Git Submodule：
   ```bash
   git submodule add -b main https://github.com/nunocoracao/blowfish.git themes/blowfish
   ```

### 階段四：配置清理
9. `config/_default/hugo.toml`：
   - `baseURL` = 協會正式域名（待確認）
   - `theme = "blowfish"`
   - 刪除 `module.toml`（不再需要 `path = "../.."` 依賴）
10. `config/_default/params.toml`：
    - 移除 `buymeacoffee.identifier = "nunocoracao"`
    - `showEdit = false`（或更新 editURL）
11. 更新 `AGENTS.md`、`MEMORY.md` 的啟動命令與部署說明

### 階段五：驗證與提交
12. `hugo server` 無參數啟動，`http://localhost:1313/` 正常
13. 所有語言頁面（zh-tw、zh-cn、en、vi）可訪問
14. 山東 AI 參訪文章正常顯示
15. `hugo --minify --gc` 無 error
16. `git add -A && git commit` 重整完成，push 到 main
17. 在 CF Pages 後台更新根目錄設定從 `exampleSite` 改為 `/`，確認自動建置成功
